# Interfaces2026-prueba

Versión provisoria del TPE 2 de Interfaces.

## Tecnologías

- HTML5
- CSS3
- JavaScript puro
- Sin frameworks

## Estructura

- `index.html`: landing pública y planes.
- `pages/login.html`: inicio de sesión.
- `pages/registro.html`: registro con animación de éxito.
- `pages/home.html`: Home Mobile First + versión desktop.
- `pages/juego.html`: página de Spider-Peg con galería animada.
- `css/`: estilos generales y estilos por página.
- `js/`: scripts separados por página.
- `assets/img/`: imágenes a incorporar.

## Requisitos del TPE cubiertos

- Navegación entre landing, login/registro, Home y juego.
- Tres tipos de hover diferentes en botones.
- Loading de Home de 5 segundos con porcentaje y spinner CSS.
- Galería de Spider-Peg con transición animada.
- Registro correcto con animación.
- Juegos con títulos reales y de distinta longitud.
- Home desarrollado Mobile First con media queries para desktop.

Las imágenes no están incluidas todavía. Los nombres esperados están documentados en `assets/img/README.md`.
